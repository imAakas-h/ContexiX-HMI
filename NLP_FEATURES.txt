================================================================================
SUPPORTED FILE FORMATS
================================================================================

Machine Data (JSON):
  Required fields:
    - collection_info: source, duration, sampling_interval, start_time, end_time
    - data: array of readings with timestamp, node_id, tag, value, datatype, quality

Node Metadata (JSON):
  Structure:
    - NodeList: array of nodes with NodeId, Name, DataType, Description
    - FolderList: nested folder structure (optional)

Node XML (XML):
  Format: OPC-UA NodeSet2 (standard)
  Elements: UAVariable, UAObject, References

Config (YAML):
  Sections:
    - machine: name, etc.
    - nodes: node_id overrides
    - engines: thresholds for alarm/anomaly/health
