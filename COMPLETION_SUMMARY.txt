================================================================================
CUSTOMIZATION
================================================================================

Alarm Thresholds - Edit config.yaml:
  engines:
    alarm:
      thresholds:
        Temperature:
          high: 30.0    # Change this
          low: 10.0     # Or this

Health Scoring - Edit config.yaml:
  engines:
    health:
      scoring:
        critical_alarm: -40   # More severe
        warning_alarm: -20

Machine Name - Edit config.yaml:
  machine:
    name: "My Machine"

Units - Edit config.yaml:
  nodes:
    "ns=2;i=2":
      unit: "°C"

UI Colors - Edit app/ui/dashboard.py:
  setup_style() method

Graph Styling - Edit app/ui/graphs.py:
  _plot_variable() method
