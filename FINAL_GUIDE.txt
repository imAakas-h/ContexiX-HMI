================================================================================
FILE UPLOAD - WHAT YOU CAN DO
================================================================================

UPLOAD MACHINE DATA:
  File → Upload Machine Data
  Select: your_machine_data.json
  
  Format required:
    {
      "collection_info": {...},
      "data": [
        {
          "timestamp": "...",
          "node_id": "ns=2;i=2",
          "tag": "Temperature",
          "value": 22.5,
          "datatype": "float",
          "quality": "StatusCode(value=0)"
        }
      ]
    }

UPLOAD NODE METADATA:
  File → Upload Node Metadata
  Select: your_nodes.json
  
  Can include:
    • Node IDs and names
    • Data types
    • Descriptions
    • Custom properties

UPLOAD NODE XML:
  File → Upload Node XML Definitions
  Select: your_definitions.xml
  
  Standard OPC-UA NodeSet2 XML format

UPLOAD CONFIG:
  File → Upload Config
  Select: your_config.yaml
  
  For custom thresholds and settings

8. ANOMALIES
   Any unusual patterns detected

9. RECOMMENDATIONS
   What to do based on analysis
