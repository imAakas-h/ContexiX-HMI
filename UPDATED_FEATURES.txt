FEATURE 2: NLP-READY SUMMARY EXPORT
================================================================================

NOW YOU CAN:
  ✓ Generate machine context in NLP-friendly format
  ✓ Export to text file
  ✓ Use with ChatGPT, Claude, or any LLM
  ✓ Feed AI systems structured machine data
  ✓ Automate insight generation
  ✓ Create audit trails

EXPORT FORMAT INCLUDES:
  • Executive Summary
  • Machine State Analysis
  • Current Sensor Readings
  • Health Factors
  • Active Alarms (with timestamps)
  • Trend Analysis
  • Statistics
  • Detected Anomalies
  • Recommendations

HOW TO USE:
  1. Load data (upload files + click "Load & Process")
  2. File → Export NLP Summary
  3. Choose save location
  4. nlp_summary.txt created
  5. Paste content into ChatGPT/Claude
  6. Ask for analysis/recommendations

EXAMPLE LLM PROMPTS:
  "Analyze this machine context and provide maintenance recommendations"
  "What could cause these alarms and anomalies?"
  "Generate an executive summary for management"
  "Predict potential equipment failures based on this data"
  "What immediate actions should be taken?"
