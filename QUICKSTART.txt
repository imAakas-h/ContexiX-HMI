CUSTOMIZING THRESHOLDS
================================================================================

Edit config.yaml to adjust alarm triggers:

    engines:
      alarm:
        thresholds:
          Temperature:
            high: 25.0    # Raise to 30.0 to be less sensitive
            low: 15.0     # Lower to 10.0 to be less sensitive
          Pressure:
            high: 1.3
            low: 0.8

Then reload in dashboard: File → Load Data

TROUBLESHOOTING
================================================================================

❌ UI won't start
  → Run: python test_ui.py
  → Install: pip install -r requirements.txt

❌ No graphs visible
  → Check that machine_data_5min.json exists
  → Verify data contains numeric values
  → Check that matplotlib is installed

❌ No alarms showing
  → Check config.yaml thresholds
  → Verify threshold values match your data range
  → Example: Temperature range is 14.7-25.3°C
           Threshold of 85°C will never trigger

❌ Wrong values in graphs
  → Verify machine_data_5min.json format
  → Check node IDs match metadata files
  → Review data in JSON file directly

❌ Units showing as "None"
  → Update config.yaml with units for each node
  → Format: 
      nodes:
        "ns=2;i=2":
          unit: "°C"

❌ API won't start
  → Check port 8000 is available
  → Verify fastapi is installed
  → Try different port: uvicorn run_api:app --port 8001
