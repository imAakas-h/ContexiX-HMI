TROUBLESHOOTING
================================================================================

Problem: Dashboard won't start
Solution:
  • Ensure Tkinter is installed: python -m tkinter
  • Install matplotlib: pip install matplotlib
  • Run: python test_ui.py

Problem: No graphs showing
Solution:
  • Verify machine_data_5min.json exists
  • Check data format is correct
  • Ensure data contains numeric values

Problem: No alarms detected
Solution:
  • Check config.yaml thresholds
  • Verify threshold values match data range
  • Review alarm logic in alarm_engine.py

Problem: Wrong units displayed
Solution:
  • Update units in config.yaml
  • Verify node mapping is correct
  • Check node_metadata enrichment

CUSTOMIZING THE DASHBOARD
================================================================================

To modify colors, fonts, or layout:

1. Edit app/ui/dashboard.py
   • setup_style() - Configure TTK style
   • Colors: bg_color, fg_color, accent_color

2. Edit app/ui/graphs.py
   • Figure settings (DPI, colors, size)
   • Subplot layout (num_cols, num_rows)
   • Plot colors and styling

3. Edit config.yaml
   • Alarm thresholds
   • Machine name
   • Health scoring

================================================================================
