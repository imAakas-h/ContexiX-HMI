================================================================================
TROUBLESHOOTING
================================================================================

Problem: UI won't start
Solution:
  $ python test_ui.py
  $ pip install -r requirements.txt

Problem: No alarms showing
Solution:
  Check config.yaml thresholds
  Verify threshold values match data

Problem: No graphs displaying
Solution:
  Verify machine_data_5min.json exists
  Ensure file is valid JSON

Problem: Wrong units
Solution:
  Edit config.yaml nodes section
  Add unit: "°C" for each node

================================================================================
PYTHON USAGE
================================================================================

from app.main import MachineContextEngine

# Initialize
engine = MachineContextEngine(
    config_file="config.yaml",
    node_metadata_json="nodesfile.json",
    node_metadata_xml="BoilerModel2.NodeSet2 (1).xml"
)

# Process data
context = engine.process("machine_data_5min.json")

# Access results
print(context.machine_state)        # RUNNING
print(context.health_score)         # 0-100
print(len(context.active_alarms))   # 6
print(len(context.anomalies))       # Count
print(context.current_readings)     # Dict of readings
